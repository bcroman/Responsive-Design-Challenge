# Responsive Design Challenge

## Project Description
This project is a responsive design challenge built using
HTML and CSS.  

The aim of this challenge was to create a webpage
that adapts to desktop, tablet, and mobile screens
based on a provided wireframe.

## Features
- Responsive design for different screen sizes
- Hamburger navigation menu on mobile
- Flexible image and text sections
- Mobile-friendly layout
- CSS media queries

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Flexbox
- Media Queries

## Responsive Breakpoints
| Device | Screen Size |
|--------|-------------|
| Mobile | 600px and below |
| Tablet | 601px - 1024px |
| Desktop | Above 1024px |

## How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Resize the browser to test responsiveness.
